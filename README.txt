HOW TO RUN
1. Download and extract this ZIP.
2. Open VS Code -> File -> Open Folder -> choose the extracted folder.
3. If needed, install the Live Server extension.
4. Right-click index.html -> Open with Live Server.
5. Use the top navigation to explore all nine pages.

PHOTOS AND EXTERNAL ASSETS
The website includes multiple architectural and interior photos embedded as Unsplash image URLs in the HTML/CSS/JavaScript. An internet connection is needed to load those photos. Google Fonts also loads online. If you need an offline version, download licensed image files and replace the URLs in assets/style.css, assets/script.js and the relevant HTML pages.

FUNCTIONALITY INCLUDED
- Responsive desktop/mobile layouts and mobile navigation
- Shared branding, navigation, and footer on all pages
- Property cards with photo, location, type, sample price and features
- Filters for purpose, type, and city
- Home search redirects to the property list with filters
- Save/favourite toggle on property cards
- Property details page with sample details and enquiry link
- Contact and sell forms with basic browser validation and demo response

IMPORTANT BEFORE PUBLISHING
- The property names, prices, locations, and descriptions are illustrative sample content, not verified active listings.
- The contact forms are demo-only. They do not email you or save entries. Connect a service such as Formspree, Netlify Forms, or a backend before going live.
- Replace placeholder email/contact information with your real business details.
- Review photo licenses/terms and replace any images as needed.
- The local Live Server URL is only visible on your computer. Publishing online requires hosting, e.g. GitHub Pages or Netlify.
